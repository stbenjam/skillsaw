# Changelog

## 0.1.0

- First Marketplace release of skillsaw for VS Code.
- Report CLI findings in the Problems panel and on source lines after saves.
- Keep diagnostics current across multiple workspace folders, symlink aliases,
  file operations and unsaved edits.
- Offer installation instructions and an executable picker when the CLI is missing.
- Show the configured executable and CLI report version in the output channel.
- Respect workspace trust, repository configuration and custom rule plugins.
