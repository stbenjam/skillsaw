# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private
vulnerability reporting for `stbenjam/skillsaw`. Do not open a public issue
for an unpatched vulnerability or include exploit details in a public pull
request.

Include the affected version or commit, the entry point, impact, reproduction
steps, and any suggested mitigation. Reports will be acknowledged and triaged
privately before coordinated disclosure.

## Supported versions

Security fixes are made on the latest release line. Upgrade to the newest
published version before reporting a problem that may already be fixed.
